# Kart Production

The main website of Kart Production, a creative studio working across photography, graphic design, music, video editing, and book publishing, with a focus on socially meaningful projects.

**Website:** https://kartproduction.github.io/kart/

> **View-only source.** This repository is public so you can see how the site was made. The text, images, designs, and code are not free to copy or republish. See [License](#license).

---

## About

*Feel the magic of creation.*

Kart Production uses creativity for positive change. The site introduces the studio, shows its main projects, and links to everything the studio makes.

## What's on the site

It is a single page with anchor-linked sections:

- **Hero:** a short introduction, with buttons to explore the work or get in touch
- **About us:** who is behind the studio, what it does, and its mission
- **Portfolio:** the main projects
- **More from Kart Production:** links to the studio's other sites and apps
- **Contact:** a message form and ways to get in touch

### Portfolio projects

- **2020 | 20Twenty & Beyond:** civic engagement that encourages young Americans to vote and understand the candidates
- **SAVE | WAR:** environmental protection and racial justice
- **Hope For A Change:** research on how photography influences social movements
- **Photography, Design & Book:** an overview of the studio's disciplines

## How it was made

A static single-page website hosted on GitHub Pages. It uses anchor navigation, a responsive layout, and a light and dark theme toggle.
